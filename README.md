# API de Conversão de Moedas 💱

API REST construída em Java com Spring Boot que consome dados em tempo real da AwesomeAPI para converter valores entre diferentes moedas. Inclui uma interface web nativa.

🛠️ Tecnologias
- Java 21 (ou a versão que você usou)
- Spring Boot 3
- RestTemplate (Integração de APIs externas)
- HTML/CSS/Vanilla JS

 🚀 Como rodar
1. Clone o repositório
2. Rode a classe ApiConversorApplication na IDE
3. Acesse http://localhost:8080 no navegador
